# シーン：日本代表戦 — 遠藤航 vs 少林幽霊ドリブル

## 台本

もう一人の要、遠藤航の堅実な中盤の守備も、こちらの選手が地面すれすれを幽霊のようにすり抜ける動きの前では、タックルする対象を見失ってしまいます。真面目に統率されたチームほど、規格外の異物には弱いのかもしれません。日本代表の監督が試合後、冷静に「相手の重心の消し方だけ研究させてほしい」とコメントする、そんな架空の一幕も想像できます。

## 演出

| 要素 | 内容 |
|------|------|
| **少林** | 橙/白ユニ、足元ドリブル。タックルされる瞬間に半透明化してすり抜け |
| **遠藤（日本）** | 紺ユニ、中盤守備・タックル試行 → 対象を見失う |
| **カメラ** | 足元寄り（Kubo版と同様） |
