# 参照動画

## 少林サッカー (2001) — スペイン語版 720p

- **ソース**: https://ok.ru/video/7349803092643
- **ローカルファイル**: `shaolin_soccer_2001_720_es.mp4`（約 1.6GB、git には含めない）

### ダウンロード

```bash
bash blender/references/download_shaolin_soccer_okru.sh
```

または:

```bash
pip install yt-dlp
yt-dlp -f "hd/best[ext=mp4]/best" \
  -o blender/references/shaolin_soccer_2001_720_es.mp4 \
  "https://ok.ru/video/7349803092643"
```
