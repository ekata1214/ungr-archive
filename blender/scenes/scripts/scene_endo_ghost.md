# シーン：遠藤航 vs 少林 — 正面ドリブルから消失

## 台本

遠藤航の堅実な中盤の守備の前で、少林選手が真正面からゆっくりドリブル。だんだんすーっと消えていき、最後はボールだけが残る。

## 演出

| 要素 | 内容 |
|------|------|
| **少林** | 遠藤の正面でゆっくりドリブル → 徐々に半透明 → 完全消失 |
| **遠藤** | 紺ユニ、堅実に立って見失う |
| **ボール** | 少林消失後も残る |
| **カメラ** | 2人の正面、足元寄り |
