# UNGR mac UI palette

編集室／アーカイブ室。光らない。赤は強調だけ。

| Token | Hex | Use |
|---|---|---|
| bg | `#0A0A0A` | terminal / desktop base |
| surface | `#141414` | panels |
| border | `#2A2A2A` | lines |
| text | `#E8E8E8` | primary |
| muted | `#888888` | secondary |
| accent | `#E10600` | cursor, errors, selection edge |
| accent-dim | `#8B0000` | rare dim red |
| green | `#8AAB2E` | success / git clean (site lime family, muted) |
| yellow | `#E8A838` | warn |
| blue | `#6B8CAD` | info only, desaturated |

Font:
- Terminal: `JetBrainsMono Nerd Font` → fallback `JetBrains Mono` → `IBM Plex Mono`
- UI: system or IBM Plex Sans JP (optional)
