# 企画メモ：かわいい弱者／境界の消費（仮）

## 仮タイトル案
- かわいい弱者がこんなに流通する理由
- ちいかわとタコピーとみいちゃんのあいだ
- 弱者性が癒やしになる国の話
- 「わかる」が先に来る物語たち

## 芯（チャンネル批評軸）
人間が勝手に作った価値観・物語の矛盾。
弱さ／生きづらさを、かわいい器に入れて消費する文化。
推奨ではなく記述。ラベリング消費への違和感も含めて記録する。

## 扱う作品（仮）
- ちいかわ（ナガノ）… かわいい＋労働／検定／失敗の反復
- タコピーの原罪（タイザン5）… かわいい器＋子どもの地獄
- みいちゃんと山田さん（亜月ねね）… 夜の街×搾取。診断名は公式未提示／作者は読者判断に委ねると発言

※「境界知能もの」と断定しすぎない。読者側のラベリング自体を対象化する。

## 起承転結（骨子）
### 起
最初は「気持ちわる」から入る。かわいいのに痛い。癒やされるはずが、弱者性が商品に見える。

### 承
日本で量産されやすい理由
1. かわいい＝安全装置（直視しづらいものをスクロール可能にする）
2. 学校／バイト／夜の街が物語装置として強い
3. 「境界」（制度の穴）言説のメディア化
4. SNS考察産業が同じレンズで束ねる

海外にもmiseryものあるが、kawaiiで包む密度が違う、と整理。

### 転
「日本に弱い人が多い」ではない。
弱い人をかわいく見せて、痛みごと回せる産業が強い。
日経メディカルのちいかわ論的な「弱者性の癒やし消費」への違和感を接続。
みいちゃんを診断名で確定しない／作者コメントで線引き。

### 結
気持ち悪さは感覚異常じゃない。消費の形が見えている。
それでも読む／見るなら、かわいいで終わらせず、構造として受け取る。
アーカイブとして残すのは、作品賛美でも糾弾でもなく、流通の地図。
